PokeRogue for the PS Vita, 1.0. **Steadier battles in long sessions, an optional 30 fps lock, and quicker screens.**

Online play with cloud saves, offline play, sound, gamepad controls, save import/export and the built-in keyboard for logging in all work. Battles run at about 25-45 fps depending on the map and how far into a run you are. If you prefer an even frame rate, turn on the new 30 fps lock.

This app runs the real PokeRogue web game on the Vita. It does not include a modified copy of the game. It is a small purpose-built "browser" (QuickJS-ng plus the web features the game uses, with native code for the heaviest parts of Phaser's rendering) that loads the game from pokerogue.net (or the offline build). A few small pieces of the game's code are swapped for equivalents that do less work as the game loads; `gamefix=0` in `ux0:data/pokerogue/config.txt` turns that off.

## What's new since 0.93
- **30 fps lock:** turn it on with the "30 fps lock" toggle on the start screen, or with L + R + □ during play (a notice shows the new setting, and it is remembered). Frames then come at an even 30 per second instead of varying between 30 and 45. `fps30=1` in `config.txt` does the same.
- **Battles no longer slow down as a run goes on:** every timer the game finished with (such as the play time timer at each battle, or a fainting Pokémon's cry) stayed behind and was checked every frame. After 25 minutes that took about a tenth of a battle frame's work. Finished timers are now removed.
- **Less hidden work:** the starter select screen stays loaded for the whole run, and its ~90 Pokémon icons kept animating while it was hidden. They are now updated only when the screen is shown again.
- **Faster party screen:** the game builds the party screen anew each time it opens. Its texts no longer make a GPU texture each before being drawn, and reopening the screen reuses the texts drawn last time. Opening it went from about 330 ms to about 200 ms on the console.
- **Starting a new run** is about 0.7 s shorter: the ~1,500 texts the game builds then no longer create and delete a throwaway GPU texture each.
- **Fewer pauses mid-battle:** when memory needs cleaning up after the game saves your run at the start of a wave, it now happens behind the loading screen instead of later in the middle of a battle.
- **The first start after installing** compiles the game's code again (more than a minute), because the app's small changes to it were updated. Later starts load it from the memory card.

Earlier changes are listed in the notes of 0.93, 0.81-beta, 0.72-beta and 0.69-beta.

## Two ways to play
Every time the app starts, a start screen lets you pick:

- **Play online:** the live game from pokerogue.net, so you always get the current version. You log in with your PokeRogue account and your saves are in the cloud, as in the browser. Needs Wi-Fi.
- **Play offline:** an offline build of PokeRogue on the memory card. No login, and saves stay on this Vita. The first time, the start screen offers **Download offline game**. This downloads `game.zip` (about 530 MB) from the latest release of [Admiral-Billy/pokerogue](https://github.com/Admiral-Billy/pokerogue/releases), the same build Admiral-Billy's PokeRogue App uses for its offline mode, to `ux0:data/pokerogue/`. You need Wi-Fi for the download. The game runs straight from that file, with no unpacking. Press ○ to cancel the download, and it continues where it stopped next time. When a newer build is released, the start screen offers **Update offline game**.

The start screen remembers your last choice and selects it for you next time.

## Requirements
- A hacked PS Vita (HENkaku, h-encore or Ensō). Tested on firmware 3.65.
- **Enable Unsafe Homebrew** turned on in Settings → HENkaku Settings. The app is marked unsafe so it can raise the CPU clock.
- `libshacccg.suprx` (Sony's shader compiler) installed at `ur0:data/libshacccg.suprx`. The app compiles the game's shaders with it and does not start without it. It is normally installed with ShaRKBR33D, which extracts it from your console's own files. It cannot be included here.
- VitaShell, to install the .vpk.
- Wi-Fi for online mode and for downloading the offline game.
- For offline mode, about 550 MB free on ux0: (the app checks before downloading).

## Install
1. Copy `pokerogue-1.0.vpk` to the Vita (for example with VitaShell's FTP or USB mode).
2. In VitaShell, press ✕ on the .vpk to install it, and accept the permissions prompt. Installing over an earlier version keeps your offline game and saves.
3. Start **PokeRogue** from the LiveArea.
4. On the start screen, choose **Play online** or **Play offline** / **Download offline game** with the D-pad or left stick and ✕ (or START), or tap it.

The first start is the slowest: the app compiles the game's code and prepares its shaders. Both are cached, so later starts are faster. In online mode the code is compiled again once each time PokeRogue publishes an update (more than a minute on that start).

## Controls
- **Buttons and sticks** reach the game as a PlayStation-style gamepad, so the game uses its own gamepad controls and shows PlayStation button icons. L and R are L1 and R1.
- **Rear touchpad:** touch its upper half on the left for L2 or on the right for R2 (in starter select: change gender / ability). The lower half, where your fingers rest, does nothing, and the rear touchpad is off while a text field (such as the login form) is on screen.
- **Front touchscreen:** works as touch or mouse input. You can tap buttons and menus.
- **L + R + □:** turn the 30 fps lock on or off.
- **START + SELECT (held together):** quit the app.

**Logging in (online mode):** selecting the username or password field opens the app's keyboard: D-pad or stick to move, ✕ type, ○ delete, △ space, □ capitals, START done, SELECT cancel. You can also tap the keys. To log in, tap the game's login button or select it and press ✕.

## Known limitations
- **Some moments still pause:** starting a new run (several seconds while the game rebuilds its screens), opening starter select after that, the first time a move's animation is used, opening the party or summary screen, and saving after a wave. That is the game's own work on one CPU core.
- **Very long sessions:** the game keeps everything it loads for the whole run (sprites, sounds), about 30 MB more per hour. After several hours in one session that alone can fill the Vita's memory; restarting the app clears it. Late in long sessions you may see the loading screen for 1-3 s now and then while memory is cleaned up.
- **Online saves are refused** if PokeRogue is saved from another device during your session. Close it on the other device.
- **Signing in with Discord or Google isn't possible**; log in with your PokeRogue username and password.
- The game's "submit" button (the DualShock touchpad click) isn't mapped; tap the button on screen or select it and press ✕. Most game settings are untested.

## Logs and bug reports
To write a log, create `ux0:data/pokerogue/config.txt` containing the line `log=1`. The app then writes `ux0:data/pokerogue/log.txt` (and keeps the previous run's as `log-prev.txt`). Bug reports are welcome in [GitHub Issues](https://github.com/krappaU/pokerogue-vita/issues). Please attach the log and say what you did and whether you were playing online or offline.

Offline saves, the downloaded game and the prepared shaders are stored in `ux0:data/pokerogue/`. Deleting that folder deletes them.
