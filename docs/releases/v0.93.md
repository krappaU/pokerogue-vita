PokeRogue for the PS Vita, 0.93: the first release that isn't a beta. **Faster battles that stay fast in long sessions, no more out-of-memory hangs, and all four shoulder buttons.**

Online play with cloud saves, offline play, sound, gamepad controls, save import/export and the built-in keyboard for logging in all work. Battles run at about 25-45 fps: early waves and simpler maps at the top of that range, busy maps late in a run (such as the Temple) at about 27-30 fps.

This app runs the real PokeRogue web game on the Vita. It does not include a modified copy of the game. It is a small purpose-built "browser" (QuickJS-ng plus the web features the game uses, with native code for the heaviest parts of Phaser's rendering) that loads the game from pokerogue.net (or the offline build). A few small pieces of the game's code are swapped for equivalents that do less work as the game loads (see below); `gamefix=0` in `ux0:data/pokerogue/config.txt` turns that off.

## What's new since 0.81-beta
- **Faster battles:**
  - Phaser's animation stepping (tweens) runs in native code, about five times faster per animation.
  - The battle map's colours (day/night, terrain) are worked out once per frame instead of once per sprite, and settings that didn't change aren't sent to the GPU again.
  - Each Pokémon's colour tables (128 values each) were sent to the GPU every frame even when nothing had changed. Now they are sent only when they change.
  - Transparent parts of the battle map cost the GPU much less, and the palette work that makes shiny Pokémon several times more expensive to draw now skips their transparent pixels.
  - The gamepad and the game's hidden login fields no longer do work every frame when nothing changed.
- **Long sessions stay fast:** each visit to the party screen left its Pokémon icons behind, and an endless animation kept moving all of them, so battles got slower the longer you played. Icons of closed screens are now dropped.
- **Fixed: the game could stop after about an hour.** Memory filled up with JavaScript garbage on top of everything the game keeps for the run, and a stat-change animation failed with "out of memory", which stopped the battle. Garbage is now collected before memory runs short, and a large allocation that fails is retried after a collection. Late in long sessions you may see the loading screen for 2-3 s now and then while that happens.
- **Fixed: L and R pressed two buttons each** (L1 + L2, R1 + R2), so in starter select they changed two things at once. L and R are now L1 and R1, and the rear touchpad gives L2 and R2 (see Controls).
- **Starter select:** opening it after starting a new run took up to 11 s and now takes about 5 s less. Each filter change (generation, type...) took almost a second; about two thirds of that work is gone.
- **Fixed: a short loading screen when a shiny Pokémon terastallized.** Every combination of the Pokémon shader's effects is now prepared ahead of time.
- **The first start after installing** prepares the shaders again (36 of them, "Preparing shaders N/M") and compiles the game's code again, because both changed. Later starts load both from the memory card.

## What was new in 0.81-beta
- **Faster battles:** about a third less JavaScript work per battle frame. PokeRogue's sprite drawing rebuilt each Pokémon's palette tables every frame; the app swaps those exact loops for ones that skip the all-zero case. The item counts on held items are drawn in native code.
- **Less GPU work:** the day/night tint is worked out once per sprite instead of once per pixel.
- **Fixed: Pokémon had no shadows** (since 0.69-beta), and in Temple trainer battles part of a Pokémon's sprite showed where its shadow goes.
- **Fewer pauses:** saving and the log are written by their own threads on other CPU cores.

Earlier changes are listed in the notes of 0.81-beta, 0.72-beta and 0.69-beta.

## Two ways to play
Every time the app starts, a start screen lets you pick:

- **Play online:** the live game from pokerogue.net, so you always get the current version. You log in with your PokeRogue account and your saves are in the cloud, as in the browser. Needs Wi-Fi.
- **Play offline:** an offline build of PokeRogue on the memory card. No login, and saves stay on this Vita. The first time, the start screen offers **Download offline game**. This downloads `game.zip` (about 530 MB) from the latest release of [Admiral-Billy/pokerogue](https://github.com/Admiral-Billy/pokerogue/releases), the same build Admiral-Billy's PokeRogue App uses for its offline mode, to `ux0:data/pokerogue/`. You need Wi-Fi for the download. The game runs straight from that file, with no unpacking. Press ○ to cancel the download, and it continues where it stopped next time. When a newer build is released, the start screen offers **Update offline game**.

The start screen remembers your last choice and selects it for you next time.

## Requirements
- A hacked PS Vita (HENkaku, h-encore or Ensō). Tested on firmware 3.65.
- **Enable Unsafe Homebrew** turned on in Settings → HENkaku Settings. The app is marked unsafe so it can raise the CPU clock.
- `libshacccg.suprx` (Sony's shader compiler) installed at `ur0:data/libshacccg.suprx`. The app compiles the game's shaders with it and does not start without it. It is normally installed with ShaRKBR33D, which extracts it from your console's own files. It cannot be included here.
- VitaShell, to install the .vpk.
- Wi-Fi for online mode and for downloading the offline game.
- For offline mode, about 550 MB free on ux0: (the app checks before downloading).

## Install
1. Copy `pokerogue-0.93.vpk` to the Vita (for example with VitaShell's FTP or USB mode).
2. In VitaShell, press ✕ on the .vpk to install it, and accept the permissions prompt. Installing over an earlier version keeps your offline game and saves.
3. Start **PokeRogue** from the LiveArea.
4. On the start screen, choose **Play online** or **Play offline** / **Download offline game** with the D-pad or left stick and ✕ (or START), or tap it.

The first start is the slowest: the app compiles the game's code and prepares its shaders. Both are cached, so later starts are faster. In online mode the code is compiled again once each time PokeRogue publishes an update (more than a minute on that start).

## Controls
- **Buttons and sticks** reach the game as a PlayStation-style gamepad, so the game uses its own gamepad controls and shows PlayStation button icons. L and R are L1 and R1.
- **Rear touchpad:** touch its upper half on the left for L2 or on the right for R2 (in starter select: change gender / ability). The lower half, where your fingers rest, does nothing, and the rear touchpad is off while a text field (such as the login form) is on screen.
- **Front touchscreen:** works as touch or mouse input. You can tap buttons and menus.
- **START + SELECT (held together):** quit the app.

**Logging in (online mode):** selecting the username or password field opens the app's keyboard: D-pad or stick to move, ✕ type, ○ delete, △ space, □ capitals, START done, SELECT cancel. You can also tap the keys. To log in, tap the game's login button or select it and press ✕.

## Known limitations
- **Some moments still pause:** starting a new run (about 7 s while the game rebuilds its screens), opening starter select after that, the first time a move's animation is used, opening the party or summary screen, and saving after a wave. That is the game's own work on one CPU core.
- **Very long sessions:** the game keeps everything it loads for the whole run (sprites, sounds), about 30 MB more per hour. After several hours in one session that alone can fill the Vita's memory; restarting the app clears it.
- **Online saves are refused** if PokeRogue is saved from another device during your session. Close it on the other device.
- **Signing in with Discord or Google isn't possible**; log in with your PokeRogue username and password.
- The game's "submit" button (the DualShock touchpad click) isn't mapped; tap the button on screen or select it and press ✕. Most game settings are untested.

## Logs and bug reports
To write a log, create `ux0:data/pokerogue/config.txt` containing the line `log=1`. The app then writes `ux0:data/pokerogue/log.txt` (and keeps the previous run's as `log-prev.txt`). Bug reports are welcome in [GitHub Issues](https://github.com/krappaU/pokerogue-vita/issues). Please attach the log and say what you did and whether you were playing online or offline.

Offline saves, the downloaded game and the prepared shaders are stored in `ux0:data/pokerogue/`. Deleting that folder deletes them.
