PokeRogue for the PS Vita, beta 0.81. **Faster battles, and Pokémon have their shadows again.**

Online play with cloud saves, offline play, sound, gamepad controls, save import/export and the built-in keyboard for logging in all work. Battles run at about 20-35 fps depending on the battle map: in the Ruins, about 27-32 fps, up from 17-22.

This app runs the real PokeRogue web game on the Vita. It does not include a modified copy of the game. It is a small purpose-built "browser" (QuickJS-ng plus the web features the game uses, with native code for the heaviest parts of Phaser's rendering) that loads the game from pokerogue.net (or the offline build). A few small pieces of the game's code are swapped for equivalents that do less work as the game loads (see below); `gamefix=0` in `ux0:data/pokerogue/config.txt` turns that off.

## What's new since 0.72-beta
- **Faster battles:** about a third less JavaScript work per battle frame.
  - PokeRogue's sprite drawing rebuilt each Pokémon's palette tables every frame, all zeros for most Pokémon. As the game loads, the app swaps those exact loops for ones that skip the zero case, and works a shiny Pokémon's colours out once. The game draws exactly the same values. If PokeRogue changes that code, nothing is swapped and the game runs as published.
  - The item counts on held items (one small text each) are drawn in native code, with the same output as Phaser's.
- **Less GPU work:** the day/night tint is worked out once per sprite instead of once per pixel. The background and Pokémon shaders cost about half of what they did.
- **Fixed: Pokémon had no shadows** (since 0.69-beta) and, in trainer battles in the Temple, part of a Pokémon's sprite showed under it where its shadow goes. The shader copies read the game's on/off settings wrongly on the Vita.
- **Fewer pauses:** saving (local storage) and, with logging on, the log are written by their own threads on other CPU cores. Text uploads to the GPU are about twice as fast.
- **The first start after installing** prepares the shaders again ("Preparing shaders N/20", about half a minute) and compiles the game's code again (about a minute more than usual), because both changed.

## What was new in 0.72-beta
- **Fixed: long sessions could hang a battle.** The game never removes the sprite of its stat-change animation (the arrows when a stat goes up or down), and on the Vita each one kept about 21 MB. After enough stat changes memory ran out, a stat change failed and the battle stopped moving. The app now removes those finished sprites and no longer allocates memory for their blank canvas.
- **No pause at stat changes:** each one stalled the game for about a third of a second while that large, empty texture was uploaded. On the Vita it is now created without copying any pixels.
- **With logging on (`log=1`), fewer pauses:** the log is written by its own thread on another CPU core, and its memory statistics no longer pause the game every 40 s.

## What was new in 0.69-beta (since 0.41-beta)
- **Faster battles (about 15-35 fps):** more of Phaser's rendering runs in native code. The game's shaders are rewritten for the Vita's GPU with exactly the same output. When an effect is switched off (terrain colours, tera, shiny or fusion palettes, shadows, day/night), the GPU draws with a copy of the shader that leaves it out. Together these about halve the GPU's work per battle frame.
- **Shaders are prepared once:** on the first start after installing, the loading screen shows "Preparing shaders N/19" for about half a minute. They are kept on the memory card, so later starts don't redo it.
- **Fewer stutters:** the JavaScript garbage collection runs during loading screens when it can, instead of in the middle of a battle. Graphics the game uses every turn stay in memory instead of being reloaded.
- **Faster start:** the game's code is compiled on three CPU cores, and fonts and the compiled code are cached.
- **More graphics memory:** the Vita's system keyboard is no longer used (it never opened on the console), and its memory goes to the GPU. The app's own keyboard is used for logging in.
- **Fixed:** the stats graph on the summary and egg-hatching screens showed a texture instead of the graph. A lost download could hang the game (seen at wave 60); failed downloads are now retried.
- **New LiveArea art:** the rocky coast arena backdrop by Vari, from PokeRogue's assets (CC BY-NC-SA 4.0).
- Release builds no longer contain the debug features (the debug line, the test-build updater). The log is written only when asked for (see "Logs and bug reports").

## Two ways to play
Every time the app starts, a start screen lets you pick:

- **Play online:** the live game from pokerogue.net, so you always get the current version. You log in with your PokeRogue account and your saves are in the cloud, as in the browser. Needs Wi-Fi.
- **Play offline:** an offline build of PokeRogue on the memory card. No login, and saves stay on this Vita. The first time, the start screen offers **Download offline game**. This downloads `game.zip` (about 530 MB) from the latest release of [Admiral-Billy/pokerogue](https://github.com/Admiral-Billy/pokerogue/releases), the same build Admiral-Billy's PokeRogue App uses for its offline mode, to `ux0:data/pokerogue/`. You need Wi-Fi for the download. The game runs straight from that file, with no unpacking. Press ○ to cancel the download, and it continues where it stopped next time. When a newer build is released, the start screen offers **Update offline game**.

The start screen remembers your last choice and selects it for you next time.

## Requirements
- A hacked PS Vita (HENkaku, h-encore or Ensō). Tested on firmware 3.65.
- **Enable Unsafe Homebrew** turned on in Settings → HENkaku Settings. The app is marked unsafe so it can raise the CPU clock.
- `libshacccg.suprx` (Sony's shader compiler) installed at `ur0:data/libshacccg.suprx`. The app compiles the game's shaders with it and does not start without it. It is normally installed with ShaRKBR33D, which extracts it from your console's own files. It cannot be included here.
- VitaShell, to install the .vpk.
- Wi-Fi for online mode and for downloading the offline game.
- For offline mode, about 550 MB free on ux0: (the app checks before downloading).

## Install
1. Copy `pokerogue-0.81.vpk` to the Vita (for example with VitaShell's FTP or USB mode).
2. In VitaShell, press ✕ on the .vpk to install it, and accept the permissions prompt. Installing over an earlier version keeps your offline game and saves.
3. Start **PokeRogue** from the LiveArea.
4. On the start screen, choose **Play online** or **Play offline** / **Download offline game** with the D-pad or left stick and ✕ (or START), or tap it.

The first start is the slowest: the app compiles the game's code and prepares its shaders. Both are cached, so later starts are faster. In online mode the code is compiled again once each time PokeRogue publishes an update (more than a minute on that start).

## Controls
- **Buttons and sticks** reach the game as a PlayStation-style gamepad, so the game uses its own gamepad controls and shows PlayStation button icons.
- **Front touchscreen:** works as touch or mouse input. You can tap buttons and menus.
- **Rear touchpad:** turned off. Fingers resting on the back kept pressing the game's "submit" button.
- **START + SELECT (held together):** quit the app.

**Logging in (online mode):** selecting the username or password field opens the app's keyboard: D-pad or stick to move, ✕ type, ○ delete, △ space, □ capitals, START done, SELECT cancel. You can also tap the keys. To log in, tap the game's login button or select it and press ✕.

## Known limitations
- **Battles run at about 20-35 fps**, depending on the battle map (busier backgrounds such as the Temple are slower). Some moments still pause briefly: the first time a move's animation is used, opening the party or summary screen, and saving after a wave. That is the game's own work on one CPU core, and making it faster is the main work left.
- **Online saves are refused** if PokeRogue is saved from another device during your session. Close it on the other device.
- **Signing in with Discord or Google isn't possible**; log in with your PokeRogue username and password.
- Most game settings are untested. The rear touchpad is disabled (see Controls).

## Logs and bug reports
To write a log, create `ux0:data/pokerogue/config.txt` containing the line `log=1`. The app then writes `ux0:data/pokerogue/log.txt` (and keeps the previous run's as `log-prev.txt`). Bug reports are welcome in [GitHub Issues](https://github.com/krappaU/pokerogue-vita/issues). Please attach the log and say what you did and whether you were playing online or offline.

Offline saves, the downloaded game and the prepared shaders are stored in `ux0:data/pokerogue/`. Deleting that folder deletes them.
