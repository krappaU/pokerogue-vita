# LiveArea images

Generated by `runtime/scripts/make_livearea.py` (the game's here, the updater's in
`runtime/updater/sce_sys/`). Don't edit the PNGs by hand: change the script and run it again.

The game's `icon0.png`, `livearea/contents/bg.png` and `livearea/contents/startup.png` show the
rocky coast arena backdrop (`images/arenas/rockycoast_bg.png` of
[pokerogue-assets](https://github.com/pagefaultgames/pokerogue-assets/blob/009cac30c39d3615c7b2c320c3984af368871031/images/arenas/rockycoast_bg.png))
by **Vari**, licensed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
It is cropped, scaled up and drawn over with text. These three files are therefore under
CC BY-NC-SA 4.0 as well; the text and the rest of the art are our own.

The updater's images are our own pixel art (AGPL-3.0-only, like the rest of the project).

The PokeRogue logo is not used: Pagefault Games asks that it not be reused without permission, as
that would imply endorsement.
